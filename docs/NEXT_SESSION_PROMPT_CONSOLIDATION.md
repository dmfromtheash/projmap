## Порядок работы

### Шаг 1. Опись (только чтение)

Для **каждой** рабочей копии и ветки — таблица:
- путь;
- ветка или «отвязана»;
- последний коммит и дата;
- влита ли в main (`git branch --merged`, `git log main..<ветка>`, сравнение по patch-id для cherry-pick);
- есть ли незакоммиченные правки и неотслеживаемые файлы (`git -C <копия> status --porcelain --ignored`), что это и сколько весит;
- к какому этапу дорожной карты относится — по `docs/STATE.md`, журналу, названию ветки, а также по вкладке «План» projmap;

Отдельно описать:

- папку `artifacts\` в рабочей копии `.codex`: там могут быть сборки и арт-конвейеры владельца (см. память `map-owner-art-pipelines`).

**projmap как помощник:**
- просканировать (`projmap-cli scan <копия> -o <вне Map>`) актуальную копию и подозрительные невлитые ветки и сравнить графы: какие файлы, классы и связи есть только там;

Так невлитое оценивается по смыслу, а не только по числу коммитов.

## Правила (обязательно)

- **Владельцу — только по-русски, простыми словами;** у каждого вопроса — что смотреть, где и зачем.
- **Любое удаление и перезапись — только после его «да» на конкретный список.** Хуки `guard.js` и blast-radius блокируют опасные команды — не обходить, а сообщить. Никакого `reset --hard`, `clean -fdx`, `push --force`; удалённый репозиторий не трогать без слова владельца.
- **Codex GPT-6-Astra — дополнительный агент.** Предлагай ему подходящие задачи: независимая опись, поиск риска потери данных, проверка плана удаления, ревью обновлённых путей, позже анализаторы этапа 2. **Перед каждым запуском** назови задачу, модель (`gpt-6-astra`), уровень (`high` или `xhigh`), запись или только чтение — и жди «да» (глобальное правило). Результаты Astra проверяй сам. Запуск — через `.cmd` + `Start-Process`, промпт через `- < файл`, финал — по файлу-флагу. Для записи — только в отдельной рабочей копии, которую потом убрать.
- **Запуск программ** (projmap, сборки и тесты Map) для проверок разрешён без вопросов. Окна — только на ноутбучном (не основном) дисплее; основной — внешний 2560×1440; если подключён только ноутбук, можно на нём. Данные и окна владельца не трогать.
- **Убирать за собой:** временные графы, выводы, скриншоты вне согласованных мест.
- **Коммиты** — в ветку Map по его протоколу (`tools/ai/Check-Scope.ps1`), с понятными сообщениями; push — только по слову владельца.
- **Подводные камни:**
  - PowerShell 5.1 `Set-Content`/`Get-Content` без `-Encoding` портит кириллицу — правки через Edit/Write;
  - `pwsh` нет, используй `powershell -NoProfile -ExecutionPolicy Bypass -File`;
  - файлы с «:» в имени теряются (NTFS);
  - Claude не может сам себе выдать разрешения в `.claude/settings.local.json`;
  - внешний монитор подключают и отключают на ходу.
