Этажи программы

Сверху то, что видит человек, ниже — то, на чём это держится. Выберите функцию слева: на каждом этаже появится, сколько её файлов там лежит.

Из чего сделана каждая функция

Длина полосы — сколько файлов у функции, цвет — на каком ярусе они лежат. Нажмите на функцию, чтобы увидеть её файлы по ярусам.

Карточки функций

Одна карточка — одна функция. Внутри — её «отпечаток» по этажам: какие ярусы она задевает и насколько.

Лента времени

Неделя за неделей: сколько было сохранений кода, какие функции менялись и какие этапы дорожной карты закрыты. Выбранная функция подсвечена.

От кнопки до кода

Выберите кнопку — увидите, через какие ярусы проходит её работа, шаг за шагом. Это возможный путь по связям кода (projmap), а не запись реального запуска.
