# projmap

Карта проекта для Windows: открываете папку с кодом — и видите, из чего программа состоит и как части связаны.
Работает без интернета, в сам проект ничего не пишет.

## Как начать

1. Скачайте `projmap-…-win-x64.zip` в разделе **Releases** справа и распакуйте в любую папку.
2. Запустите `projmap.exe`, нажмите **«Открыть папку проекта…»** и выберите корень репозитория.
3. Первое сканирование занимает от нескольких секунд до минуты; потом окно следит за изменениями файлов само.

Нужна Windows 10/11 x64 (WebView2 уже есть в системе). .NET устанавливать не нужно.

## Что показывает

- **Схема** — модули, папки, файлы, классы и стрелки между ними; раскрытие двойным кликом.
- **Подробное древо**, **План** (дорожная карта из Markdown), **База данных** (таблицы и кто их читает/пишет).
- **Схема связей** — программа по **ярусам** (интерфейс, сценарии, правила, данные, сервер, инфраструктура) и
  **функциям** (найденные по именам группы файлов, которые проходят через ярусы). Внутри неё ещё виды:
  «Дерево», «Плитки», «Солнце», «Созвездие», «Потоки», «Время» (недели работы и этапы плана) и
  «От кнопки» (через какие ярусы проходит работа после нажатия). Везде колесо — приближение, нажатие — внутрь,
  до файлов, классов и функций.
- Ярус файла можно исправить вручную; правки хранятся у projmap на компьютере, не в проекте.
- **Карточка «что это»** (с 0.2.0) — рядом с выбранным блоком на «Схеме» и в «Связях»: понятное имя рядом с
  настоящим, откуда это известно (из комментария · из документа · по устройству кода · по истории ·
  предположение по имени), сколько частей им пользуется, **«Где лежит»** (модуль › папки › файл, каждое открывается)
  и **«Назад»** (Alt+←) к прежнему выбору. Кнопка **«Словарь»** объясняет слова схемы.
- **«Проблемы»** — части, похожие на неиспользуемые, циклы файлов, часто меняемые файлы; это повод проверить,
  а не разрешение удалять.

Языки: C# (полный разбор Roslyn: вызовы, наследование, обработчики кнопок, `.axaml/.xaml`),
TypeScript/JavaScript/Python (импорты), SQL/Prisma/SQLite (схема), Markdown (документы, план), git (история).

## Командная строка

```
projmap-cli scan <папка> [-o graph.json] [--git-months N] [--no-members] [--timings] [--views-overrides file]
projmap-cli stats <graph.json>
projmap-cli diff <a.json> <b.json> [--ignore-git] [--ignore-positions]
```

Формат `graph.json` — `docs/GRAPH_CONTRACT.md`. ID членов C# строятся по исходному
синтаксису и не зависят от сборки проекта; ID обработчиков учитывают цель регистрации.
Рёбра `dispatch` показывают возможные реализации интерфейсных и виртуальных членов.
Старые графы остаются читаемыми, `schemaVersion` — 1.

## Сборка из исходников

.NET 10 SDK: `dotnet build ProjMap.slnx -c Release`, тесты — `dotnet test tests/ProjMap.Tests -c Release`
и `node --test tests/web` (общая навигация окна, `docs/NAVIGATION.md`).
Архив для выпуска — `tools/publish-release.ps1 -Out <папка>`.
