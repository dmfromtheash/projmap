# Сценарии для невидимого Chrome

Запуск: `node tools/e2e/headless.mjs --graph <graph.json> --script tools/e2e/scenarios/<файл>.mjs --out <папка> --root <корень проекта>`
(граф — `projmap-cli scan <проект> -o <graph.json>`). Окно на экран не выводится.

| Файл | Что проверяет |
|---|---|
| `links.mjs` | «Схема связей»: обзор, наведение, раскрытие блока → файл → класс, Esc, узкое окно, тёмная тема; наложения текста |
| `shapes.mjs` | «Дерево», «Плитки», «Солнце», «Созвездие», «Потоки»: отрисовка, нажатие внутрь, наложения текста |
| `time-path.mjs` | «Время» (этап R13 = 22 файла на Map) и «От кнопки» (кнопка PNG доходит до `LayerPngExporter`) |
| `problems.mjs` | «Проблемы» |
| `perf.mjs` | время до картинки, блокировки, кадры при зуме и перетаскивании по всем видам |

`tools/e2e/release-check.mjs <projmap.exe> <проект> <папка>` — настоящее окно выпуска в режиме `--test` (только второй
экран, свой `PROJMAP_HOME`): стартовый экран → «Открыть папку проекта…» → скан → виды; снимки CDP.
